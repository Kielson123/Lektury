## 🌟 Główne funkcje strony

1. **Gotowe, sfunkcjonalizowane konteksty**:
   - Każdy kontekst ma określony typ (np. *filozoficzny*, *historyczny*, *biograficzny*, *mitologiczny*, *intertekstualny*), omówienie relacji oraz **konkretną funkcję argumentacyjną na maturę (jak połączyć kontekst z tezą)**.
2. **Błyskawiczne wyszukiwanie i filtrowanie**:
   - Wyszukiwarka na żywo (szuka po tytule, autorze, motywie, treści kontekstu i pytaniach maturalnych).
   - Filtrowanie po kategorii (Zakres podstawowy LO, Szkoła podstawowa, Dodatkowe).
   - Filtrowanie po epoce (od Starożytności po Współczesność).
   - Filtrowanie po typie kontekstu.
   - Klikalne tagi motywów (np. `#cierpienie`, `#zbrodnia`, `#fatum`).
3. **Tryb Fiszki / Losowarka do powtórek**:
   - Pozwala wylosować lekturę z ukrytymi kontekstami, sprawdzić własną wiedzę i odkryć odpowiedzi jednym kliknięciem.
4. **Zarządzanie powtórkami (Ulubione ⭐)**:
   - Możliwość oznaczania gwiazdką lektur wymagających powtórki (zapisywane lokalnie w przeglądarce).
5. **Kopiowanie do schowka**:
   - Kopiowanie pojedynczego kontekstu lub całego zestawu w formacie Markdown do notatek szkolnych.
6. **Przewodnik CKE**:
   - Wyjaśnienie zasad oceniania kontekstu przez egzaminatorów CKE, wzorcowy 4-krokowy schemat akapitu oraz zestawienie najczęstszych błędów (wzmianka dekoracyjna, streszczanie).
7. **Tryb Ciemny / Jasny (Dark Mode)** oraz **Gotowy arkusz do druku (Print / PDF)**.

## 🚀 Jak uruchomić stronę?

Strona została stworzona w czystym standardzie HTML5, CSS3 i Vanilla JavaScript (bez konieczności instalowania Node.js, serwerów czy skomplikowanych bibliotek):

1. **Wystarczy otworzyć plik `index.html`** bezpośrednio w dowolnej nowoczesnej przeglądarce internetowej (Chrome, Edge, Firefox, Safari, Opera).
2. Opcjonalnie można uruchomić lokalny serwer HTTP, np.:
   ```bash
   # Za pomocą Pythona:
   python -m http.server 8000
   # lub npx:
   npx serve .
   ```
   i wejść na adres `http://localhost:8000`.
